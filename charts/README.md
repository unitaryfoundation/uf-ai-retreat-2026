# The three live charts

These mirror the wall charts in the Guggenheim Pavilion. Stickies added on the wall get transcribed here; entries added here can be pitched on Saturday.

- [`problems/`](problems/INDEX.md): problems worth 10x. Seeded from the pre-read.
- [`tools/`](tools/INDEX.md): tools and tricks. The running index of what people actually use.
- [`structures/`](structures/INDEX.md): structures we'd want, such as leaderboards, Lean repos, zoos, review and credit norms.

One file per entry, from the matching template in [`templates/`](../templates/). Problems and structures carry a `status`: `idea`, `pitched`, `group-formed`, `done` or `parked`.
