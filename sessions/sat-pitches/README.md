# Pitches and group formation (Saturday 1:45 PM)

Two minutes at the whiteboard, starting from the Friday charts. A pitch needs more than one person plus agents and names a verifier. It can be a structure as easily as a research problem.

A pitch is not a new kind of file. When an entry in [`charts/problems/`](../../charts/problems/INDEX.md) or [`charts/structures/`](../../charts/structures/INDEX.md) is pitched, set its `status: pitched`; if it is new, create the chart entry first. When a group forms, create `groups/<group-slug>/` and set the entry's `status: group-formed` and `group`.

Keep the running order and who joined what in `pitch-log.md` here.
