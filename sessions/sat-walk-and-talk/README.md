# Walk-and-talk (Saturday 11:00 AM)

Sixty minutes in assigned cross-cluster trios. Prompt: what problem would you attack with ten times the throughput, and what is the verifier?

- `trios.md`: the assignments (to be added by the organisers).
- `trio-<nn>.md`: one short note per trio, from [`templates/session-note.md`](../../templates/session-note.md). New problems that come up go in [`charts/problems/`](../../charts/problems/).
