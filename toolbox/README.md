# Toolbox

One reusable thing per person, dropped in before arriving: a skill, a prompt, a harness config, an `AGENTS.md`, a verifier script. More are welcome during the weekend.

Put yours at `toolbox/<first-last>/<thing>/` with a `README.md` that says, in two lines, what it is and how to use it (see [`templates/toolbox-readme.md`](../templates/toolbox-readme.md)). The first non-heading line of that README becomes the summary in [`INDEX.md`](INDEX.md).

Strip credentials, API keys and private paths before committing.
